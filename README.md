**خرمای تازه‌ی جیرفت، از نخلستان تا خانه‌ی شما با زنجیره‌ی سرد.**

## نخل جیرفت چیست؟

نخل جیرفت یک وب‌سایت فارسی و راست‌به‌چپ برای یک **سردخانه‌ی هوشمند و فروشگاه آنلاین خرما و خشکبار** در جیرفت کرمان است. مشتری محصول را مستقیم از باغ‌دار می‌خرد؛ بار در سالن‌های سردخانه با دمای ثابت ۲ تا ۴ درجه نگهداری می‌شود و با کامیون یخچال‌دار به سراسر ایران ارسال می‌شود.

## امکانات

- 🛒 **فروشگاه:** کاتالوگ مضافتی، پیارم، کلوته و خشکبار با جستجو، دسته‌بندی، صفحه‌بندی و سبد خرید با پیشرفت تا ارسال رایگان
- ❄️ **سردخانه و خرید عمده:** رزرو سالن سرد، استعلام حمل و قیمت پلکانی خرید عمده
- 👤 **حساب کاربری:** ثبت‌نام، ورود و بازیابی رمز با کد تأیید؛ داشبورد مشتری با رهگیری مرسوله در زنجیره‌ی سرد، کیف پول و باشگاه مشتریان، آدرس‌ها و رسید سفارش
- 🛠️ **پنل مدیریت:** تأیید یا حذف سفارش‌های تازه (تکی یا گروهی)، تغییر وضعیت سفارش، کنترل موجودی و قیمت، وضعیت سالن‌های سردخانه و پشتیبانی مشتریان
- 🎨 **طراحی:** پالت سبز لوگوی سردخانه، طرح‌های خطی بومی جنوب (نخلستان، بادگیر و لنج، بته‌جقه‌ی کرمان، سفال تمدن جیرفت) و انیمیشن‌های روان
- ⚡ **سرعت:** بدون CDN و کاملاً آفلاین؛ انیمیشن‌ها فقط با transform و opacity، سازگار با موبایل

## فناوری

HTML · Tailwind CSS (کامپایل‌شده) · JavaScript خالص · آیکون‌های Lucide · SVG

## ساختار

```
index.html      صفحه‌ی اصلی
css/            tailwind.css + style.css
js/             app.js (منطق سایت) + icons.js
img/            لوگو و طرح‌های خطی (img/orn)
fonts/          وزیرمتن (مجوز آزاد OFL)
```

> این نسخه‌ی نمایشی است و داده‌ها فقط در مرورگر خود کاربر ذخیره می‌شوند؛ پرداخت، پیامک و نقش‌ها باید روی سرور واقعی پیاده شوند.
