# 🌙🌴 فروشگاه نخل و ماه | خرما و خشکبار ارگانیک جنوب

وب‌سایت فارسی و راست‌به‌چپ برای **فروشگاه آنلاین خرما و خشکبار** و **سردخانه‌ی هوشمند** نخل و ماه.
مشتری محصول را می‌بیند، صفحه‌ی هر محصول را باز می‌کند، نظر می‌دهد، می‌خرد و سفارشش را در زنجیره‌ی سرد پیگیری می‌کند؛ مدیر فروشگاه سفارش‌ها، موجودی و درخواست‌های سردخانه را مدیریت می‌کند.

## امکانات

- 🛒 **فروشگاه:** دسته‌های مضافتی، پیارم، کلوته، خرمای خشک و خشکبار؛ جستجو، صفحه‌بندی، سبد خرید و کد تخفیف (هر کد یک بار برای هر نفر)
- 📦 **صفحه‌ی هر محصول** (`#product/<id>`): عکس، امتیاز ستاره‌ای، قیمت، انتخاب اندازه (جعبه ⇄ کارتن مادر)، توضیحات، مشخصات، نظرات خریداران و محصولات مشابه
- ❄️ **سردخانه و خرید عمده:** «استعلام سریع» با کد پیگیری و پیام تأیید
- 👤 **حساب کاربری:** ثبت‌نام، ورود، داشبورد مشتری (رهگیری سفارش، نمودار خرید ۱۲ ماه، آدرس‌ها، اعلان‌ها)
- 💳 **پرداخت:** درگاه زیبال (حالت آزمایشی تا وقتی سرور وصل شود)
- 🛠️ **پنل مدیریت:** سفارش‌ها، موجودی و قیمت، وضعیت سالن‌های سرد، مشتریان و پشتیبانی

## ساختار پوشه‌ها

```
src/                 ← کد خوانا؛ همیشه اینجا را ویرایش کنید
  html/              صفحه در ۴ پوشه: 1-layout (هد، هدر، فوتر، پنجره‌ها) · 2-home (صفحه‌ی اول) · 3-shop (محصولات، صفحه‌ی محصول، خرید و رسید) · 4-account (داشبورد، پنل مدیر، ورود)
  js/                منطق سایت، هر فایل یک بخش (محصولات، سبد، روتر، صفحه‌ی محصول، حساب، …)
  css/               استایل‌ها، هر فایل یک بخش + vendor/tailwind.css
tools/
  build.mjs          ساخت فایل‌های نهایی از src
  serve.mjs          پیش‌نمایش محلی با ساخت خودکار
index.html  js/app.js  css/style.css  css/tailwind.css    ← خروجیِ ساخته‌شده (دستی ویرایش نکنید)
img/                 لوگو، عکس محصولات (img/p) و آیکون‌ها (img/icons)
fonts/               پیدا و یکان بخ
server/              فایل‌های PHP برای هاست ایرانی: پرداخت زیبال و استعلام سریع
```

بالای هر فایل در `src` یک توضیح کوتاه هست که می‌گوید آن بخش چه می‌کند و کجا باید تغییرش داد.

## اجرا و ساخت

به Node.js نسخه‌ی ۱۸ یا بالاتر نیاز دارید؛ هیچ پکیجی نصب نمی‌شود.

```bash
npm run dev      # پیش‌نمایش در http://localhost:5173 ؛ هر تغییر در src خودکار ساخته می‌شود
npm run build    # ساخت index.html و js/app.js و css/*.css از روی src
```

> فایل `index.html` را مستقیم از روی دیسک (file://) باز نکنید؛ مرورگر فونت‌ها را مسدود می‌کند. از `npm run dev` استفاده کنید.

## کجا چه چیزی را عوض کنم؟

| می‌خواهید… | فایل |
|---|---|
| محصول، قیمت یا عکس اضافه/عوض کنید | `src/js/01-products.js` |
| توضیحات و مشخصات صفحه‌ی محصول | `src/js/01b-product-info.js` |
| متن کوتاه زیر نام محصول | `src/js/03-product-card.js` (DESC) |
| کد تخفیف | `src/js/02-state.js` (PROMOS) |
| آیدی بله، اینستاگرام، تلفن | `src/html/2-home/15-home-contact.html` و `src/html/1-layout/70-footer.html` |
| ارزش غذایی و خواص هر محصول | `src/js/01b-product-info.js` (NUTRI و GOOD) |
| سرور پرداخت / استعلام | `src/js/13-checkout-pay.js` (PAY.api) و `src/js/11-inquiry.js` (INQUIRY.api) |

## امنیت

- همه‌ی متن‌هایی که کاربر می‌نویسد (نام، آدرس، نظر، استعلام) پیش از نمایش escape می‌شوند.
- سیاست امنیتی محتوا (CSP) فقط فایل‌های خود سایت را اجازه می‌دهد؛ هیچ اسکریپت درون‌خطی‌ای وجود ندارد.
- سایت هیچ‌وقت شماره کارت یا رمز بانکی نمی‌گیرد؛ پرداخت فقط روی صفحه‌ی امن بانک انجام می‌شود.
- ⚠️ تا وقتی سرور وصل نشده، حساب‌ها، سفارش‌ها و نظرات فقط در مرورگر هر کاربر ذخیره می‌شوند. ورود، نقش مدیر، قیمت نهایی و تأیید پرداخت باید روی سرور واقعی انجام شوند (راهنما: `server/README.md`).
